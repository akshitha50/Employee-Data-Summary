# Task 31 – Employee Data Summary

## Project Overview
This project focuses on analyzing employee data using Microsoft Excel. The dataset contains employee details such as Employee ID, Department, Role, and Salary.

The main objective is to summarize employee information, analyze salary distribution, and compare departments and job roles using Excel tools.

## Tools Used
- Microsoft Excel
- PivotTables
- Excel Formulas
- Charts and Data Visualization

## Dataset Details
The dataset contains 20 employee records with the following columns:
- Employee_ID
- Department
- Role
- Salary

## Tasks Performed
1. Created and organized an employee dataset.
2. Formatted the dataset as an Excel table.
3. Calculated total employees.
4. Calculated average, median, and highest salary.
5. Created PivotTables for department-wise analysis.
6. Created role-wise salary summaries.
7. Developed charts for data visualization.

## Key Insights
- Total Employees: 20
- Average Salary: ₹44,900
- Median Salary: ₹43,500
- Highest Salary: ₹65,000
- IT Department has the highest employee count with 6 employees.

## Charts Created
1. Employee Count by Department
2. Average Salary by Department
3. Average Salary by Role

## Learning Outcomes
Through this task, I learned how to use Excel formulas, create PivotTables, summarize employee information, and represent data through charts.

## Conclusion
This project helped me improve my practical Excel skills and understand how employee data can be analyzed to generate meaningful insights.
